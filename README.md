# J-FAS

Minimal luxury jewelry and fashion storefront for the HNG 15 Lesson 2 individual task. Built as a mobile-first React/TypeScript MVP with a local demo catalog and browser-persisted cart/order history.

## Run locally

```sh
npm install
npm run dev
```

Checks: `npm run lint`, `npm run typecheck`, and `npm run build`.

See [AGENTS.md](./AGENTS.md) for architecture, integration assumptions, status, and next steps.
